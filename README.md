# SSE 643 Module 5 Discussion

This project demonstrates a 3D scene from my favorite video game series: Kingdom Hearts. Built using [Three.js](https://threejs.org/). It includes a Keyblade model shooting a glowing beam shooting out of the keyblade into a keyhole

## Setup Instructions
1. **Clone the Repository**:
   ```bash
   git clone https://github.com/InkytheGreat/Module-5-Discussion.git
   cd Module-5-Discussion
   ```

2. **Install Dependencies**:
   Ensure you have [Node.js](https://nodejs.org/) installed, then run:
   ```bash
   npm install
   ```

3. **Run the Project**:
   Start the development server using Vite:
   ```bash
   npx vite
   ```

4. **View in Browser**:
   Open your browser and navigate to the address that vite specifies.
